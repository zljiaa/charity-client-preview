# 联合机构负责人工作台

[打开工作台](index.html) · [组织详情](index.html?view=identities&organization=A001) · [添加组织](index.html?view=identities&application=new)

三个标签统一展示关联组织、受邀店铺和社会资源。身份页可添加商协会组织，填写基本资料、登记证书及微信收款资料；支持保存草稿、提交、查看进度和撤回。申请审批通过后建立组织成员关系。

组织名称和“查看组织”进入完整资料页，参考商家组织管理，连续展示基本资料、资质材料、收款资料及成员信息，支持分区定位、刷新和浏览器返回。

全部数据为演示；申请、上传材料及资源记录保存在当前浏览器。

# 善集平台管理工作台

[公网原型](https://zljiaa.github.io/charity-client-preview/workbench/roles/01-super-admin/index.html)

系统超级管理员与商家、基金会、商协会、高校管理员按授权管理平台事务。

项目、项目活动、公益行动直接使用基金会工作台的共用页面：列表、详情选项卡、创建编辑、模板字段、图文与轮播素材、客户端实时预览及草稿校验均由 ../shared/organization.js 和共用内容组件提供。系统超级管理员、系统基金会管理员选择主办基金会后创建内容，申请进入平台审批中心；审批结果同步到同一份内容版本。

基金会组织详情的“项目管理”也进入同一页面。平台外壳提供基金会选择与三个内容入口。

共用内容与基金会工作台使用同一浏览器会话的草稿及申请存储；组织、订单与平台配置保留既有演示数据。

[查看截图](原型截图.md)

验证脚本：verify-platform.cjs 检查实际基金会页面的一致性及系统创建、审批流程；verify.cjs 检查组织、订单、分账、客服及原审批业务。

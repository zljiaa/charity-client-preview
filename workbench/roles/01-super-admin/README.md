# 善集平台管理工作台

[打开工作台](index.html) · [项目与活动](index.html?view=content) · [新建公益项目](index.html?view=content&kind=项目&edit=1)

工作台供系统内部人员管理善集业务。演示角色包括系统超级管理员、系统商家管理员、系统基金会管理员、系统商协会管理员和系统高校管理员；菜单、组织与审批列表按对应角色展示。

- 工作概览：入驻组织、待审批、订单实付、公益款到账、7 / 30 天订单趋势、快捷入口及最近操作。
- 组织管理：商家、基金会、商协会及高校列表与详情，沿用店铺、商品、订单及分账的查询层级。
- 项目与活动：查询及创建公益项目、项目活动和公益行动，选择主办基金会和所属项目，支持草稿、图片、模板、名额、捐赠配置、客户端预览和发布审批。
- 审批中心与我的申请：查询提交版本及审批结果，处理通过 / 驳回，撤回待审申请后继续修改。
- 平台管理：Banner、微信客服、账号与系统角色、平台协议及操作记录。

系统基金会管理员及系统超级管理员可创建三类公益内容；基金会项目页保留对应新建入口。项目活动提供报名、捐款、捐赠参会、宣发模板；公益行动提供报名、宣发模板。

原型数据为虚构示例，操作保存在当前浏览器，不连接真实账号、支付、审批或短信服务。正式系统的权限及状态校验由服务端执行。

验证结果及页面截图见目录中的 platform-verification.json、verification.json 和 previews；截图说明见《善集平台管理工作台原型截图》文档。
